# homebrew-tap

Homebrew tap for i-zhirov tools.

## DOSker

DOSker is a Docker-like system for pre-configured DOS systems. The formula
supports macOS arm64 and Linux x86_64.

```sh
brew tap i-zhirov/tap
brew install dosker
```

The formula installs QEMU. Run `dosker doctor` after installation to check the
engine.
